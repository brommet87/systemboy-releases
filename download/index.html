Installation
  1. Run SystemBoy-Installer.exe.
  2. If Windows shows “Windows protected your PC”, click More info and Run anyway.
  3. Choose a language, accept the terms, confirm the location – the installer downloads, verifies and installs SystemBoy.

macOS

macOS 12 or later · Apple Silicon & Intel
Installer for macOS Without installer: direct packages
Installation
  1. Open the DMG and start “SystemBoy Installer”.
  2. If macOS reports an unverified developer, open it via right-click › Open.
  3. The installer picks Apple Silicon or Intel itself and puts SystemBoy in Applications (it may ask for your password).

Linux: which package is right for me?

SystemBoy is available for all major Linux families. Not sure? The AppImage runs everywhere. Just paste the command into a terminal – it downloads the package and installs it.

Ubuntu, Debian, Linux Mint, Pop!_OS, Zorin OS, elementary OS
DEB
wget -O /tmp/systemboy.deb https://github.com/brommet87/systemboy-releases/releases/latest/download/systemboy-linux-amd64.deb && sudo apt install /tmp/systemboy.deb
Fedora, openSUSE, Red Hat, Rocky Linux, AlmaLinux
RPM
sudo dnf install https://github.com/brommet87/systemboy-releases/releases/latest/download/systemboy-linux-x86_64.rpm
Arch Linux, Manjaro, CachyOS, EndeavourOS, Garuda
Pacman
curl -fLo /tmp/systemboy.pacman https://github.com/brommet87/systemboy-releases/releases/latest/download/systemboy-linux-x86_64.pacman && sudo pacman -U /tmp/systemboy.pacman
Everything else – or no installation
AppImage
(wget -qO ~/SystemBoy.AppImage https://github.com/brommet87/systemboy-releases/releases/latest/download/SystemBoy-linux-x86_64.AppImage || curl -fLo ~/SystemBoy.AppImage https://github.com/brommet87/systemboy-releases/releases/latest/download/SystemBoy-linux-x86_64.AppImage) && chmod +x ~/SystemBoy.AppImage && ~/SystemBoy.AppImage

openSUSE: sudo zypper install https://github.com/brommet87/systemboy-releases/releases/latest/download/systemboy-linux-x86_64.rpm

First start: warnings are normal

SystemBoy isn't signed with a paid certificate yet. Windows and macOS therefore warn the first time you open it – this applies to new programs without a certificate in general.

Windows SmartScreen

  1. The message “Windows protected your PC” appears.
  2. Click More info.
  3. Choose Run anyway – Windows won't ask again.

macOS Gatekeeper

  1. A message about an “unverified developer” appears.
  2. Open the app via right-click › Open – or click Open Anyway under System Settings › Privacy & Security.
  3. macOS asks once later for permission to take screenshots.
